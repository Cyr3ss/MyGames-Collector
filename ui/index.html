Авторизация в MY.GAMES

Безопасный вход через браузер без передачи паролей сторонним скриптам

🔒

Статус: Требуется вход

Для получения наград необходимо один раз авторизоваться в магазине MY.GAMES.

Как это работает:
  1. Нажмите кнопку «Открыть окно входа» ниже.
  2. В открывшемся окне официального браузера выполните вход (VK ID, логин/пароль, почта или Google).
  3. После успешного входа на сайт окно само закроется или нажмите «Я вошёл».
  4. Сессия сохраняется на несколько месяцев (Sliding Session) — повторно входить не придётся!
