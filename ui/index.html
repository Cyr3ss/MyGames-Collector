Авторизация в MY.GAMES

Безопасный вход через браузер без передачи паролей сторонним скриптам

🔒

Статус: Требуется вход

Для получения наград необходимо один раз авторизоваться в магазине MY.GAMES.

Как это работает:
  1. Нажмите кнопку «Открыть окно входа» ниже.
  2. В открывшемся окне официального браузера выполните вход (через VK ID, логин/пароль, почту или Google).
  3. После успешного входа на сайт просто закройте окно браузера.
  4. Ваша сессия автоматически сохранится, и коллектор сможет работать в фоне!
